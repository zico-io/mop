# mop:docs reference

## Slop patterns

The minimum set to fix when `unslop` is not installed.

| Pattern | Before | After |
|---|---|---|
| Em dash | The token expires — refresh it. | The token expires. Refresh it. |
| Mid-sentence colon | Note: the key is required for all calls. | The key is required for all calls. |
| "Serves as" | This page serves as a guide to webhooks. | This page explains webhooks. |
| Rule-of-three padding | Fast, reliable, and scalable. | Say the one property the reader needs. |
| Passive voice, no actor | The webhook is retried. | The server retries the webhook. |
| Inflated words | Leverage, utilize, robust | Use, use, name the property |

## Keep exactly

Product names, bold UI labels as the product shows them, numbers, and links. Brand rules from memory or the repo override the table, for example a lowercase domain or a product name's casing.
